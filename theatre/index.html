Voices & delivery

Optional neural mode downloads model files and code from Hugging Face and jsDelivr. Files may total hundreds of MB and use substantial RAM. Generation runs in your browser; first use can be slow on this PC. Nothing downloads until you choose Load.

Device voices vary. Natural, Neural or Google English voices are useful candidates to audition. Some device voices use an online service.

2D prototype. Device mode uses approximate mouth movement; neural mode maps model mouth cues to simple shapes. No account or API key required.

The script

4 lines

Use Claude: Hello! or GPT [curious]: How are you? Add Pause: 400 for a pause in milliseconds.

Expressions: neutral, happy, curious, concerned. Up to 2,000 spoken characters. English starter dialogue; no grammar correction or AI service runs here.
