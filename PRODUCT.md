# Mascot for Agents

Independent community gallery for developers and people looking for expressive GPT and Claude mascot reactions. The primary task is finding a reaction, inspecting its appearance and motion, and downloading a transparent asset or character pack.

- 2 characters, 58 expressions each, 116 reactions.
- PNG stickers at 384 px; GIF and WebP loops at 288 px and 25 fps.
- Python source is included in the character packs.
- Static hosting on GitHub Pages; no accounts or backend.
- Existing character identities, asset exports and usage notices are binding.
- Community studies, not official OpenAI or Anthropic artwork.
- Artwork and brand usage follow repository notes; code is MIT.
- Favourites are stored on the visitor's browser. No user data is sent to a server.
