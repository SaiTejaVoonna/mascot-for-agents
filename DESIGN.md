# Mascot gallery design

This pass refines the Expression Studio concept the user liked and applies it to the main website. The gallery is an Experience surface with an Operate collection: the existing pixel characters lead, while filters and downloads stay quiet and consistent.

## Direction

The subject supplies the artwork: orange rectangular Claude, mint knot GPT, expressive faces and authored animated loops. Preserve the warm paper, sage and peach surfaces selected in the concept. Use one geometric type family, Sora, to echo the block and knot geometry. Remove ornamental numbers, uppercase eyebrows, italic emphasis, decorative grids and tiny captions.

## Tokens

- Paper: #f6f4ed
- Ink: #252820
- Muted text: #5b6255
- Sage stage: #e4e9d6
- Peach stage: #f2e2d6
- Keyboard focus: #315d36
- Sora variable, self-hosted with SIL OFL licence.
- Type: 12 px minimum labels, 13–15 px UI and body, 28–32 px section titles, responsive display up to 82 px. Tracking no tighter than -0.035em.

## Structure and behaviour

Header / mascot scene and introduction / collection toolbar / gallery with desktop preview desk / downloadable packs / usage notes.

Phones use a native dialog for the selected reaction; Escape closes it and focus returns to the selected card. Filters and the selected reaction are shareable in the URL. Favourites stay local. Light and dark themes follow the system until explicitly chosen. Reduced motion starts still; explicit playback is available. Offscreen and hidden-tab previews pause. WebP falls back to GIF, then PNG.

Use movement for the existing character performances. Interface feedback is short and restrained; there are no staggered scroll reveals or floating card effects.
