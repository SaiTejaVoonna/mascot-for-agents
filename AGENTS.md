# Agent instructions

This is a cross-agent mascot asset library and static gallery. Read the root README and the mascot manifest before changing assets. Keep render sources deterministic and provider-independent. Do not overwrite approved reference files. Preview changes in the gallery and inspect them at both full size and small emote size. Do not mark assets as official or freely reusable without explicit rights information. Keep website functionality static-host compatible.

Claude identity: keep the flat rectangular orange block, side tabs and four short legs from the comparison reference. Do not add separate arms or hands. Keep expressive mouths, eyes and brows; use restrained accents and whole-body motion. GPT retains its own independent arm system.

Claude v4 uses a 48×36 rectangular body on the 96px grid, two 12×12 side tabs, and four 6×12 legs. No tiered shoulder bands, sloped outline or skinny limbs. The active assets are in assets/collection/claude-v4; older exports are legacy. Keep eyes/mouth inside the block.
