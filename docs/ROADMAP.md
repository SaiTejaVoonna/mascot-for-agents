# Roadmap

## Available in v5

- Light and dark gallery themes, saved manual preference and system-theme default.
- Text/emoji search, character/mood filters, still and GIF previews.
- 58 paired reactions per character: 116 PNGs, 116 GIFs and 116 animated WebPs.
- Fuller GPT outer knot with separate compact hands and moving feet.
- Claude reference block with attached moving tabs and four block feet.
- Staged jumps, hand waves, claps, dance/walk cycles, pointing, flag waving, typing, peeking, stumbling and foot tapping.
- Source ZIPs, manifests, contact sheets and deterministic Pillow renderer.
- Repository build workflow validates all assets before publishing.
- Chromium tests cover theme persistence, mobile layout, previews and downloads.
- GitHub Pages from main/root; legacy asset links retained.

## Future

### Next product phase, recorded 30 October 2026

1. Quality release: visually review the current UI on phones and desktop; refresh legacy browser checks and pack-builder file lists; check downloads, keyboard access, shared links, reduced motion and loading behaviour.
2. Context previews: show reactions in a chat and in a small app interface, at realistic sizes and on light/dark backgrounds.
3. Download saved reactions: collect a small selection and download a chosen format without an account.
4. Reactive companion engine: build a small event-driven character runtime and an embeddable agent-status widget. See [ENGINE_PLAN.md](ENGINE_PLAN.md).
5. Discovery: individual reaction pages, export guidance, metadata and share previews.
6. Research: observe new visitors finding and downloading a reaction; prioritize fixes from their actual difficulty.

Relevant installed skills cover design direction, critique, typography, colour, layout, writing, accessibility and motion. Candidate additions are Anthropic `webapp-testing` and Addy Osmani's `web-quality-skills` for measured reliability and performance. They are recommendations, not newly installed dependencies.

### Longer-term possibilities

- Agent Theatre implementation sequence: talking Hello, 3D campfire conversation, portable agent files, grounded movement, snow/park stages and community packs. See [THEATRE_PLATFORM_PLAN.md](THEATRE_PLATFORM_PLAN.md) for the current detailed direction.

- Scene Studio: short acted conversations, podcasts and reels from dialogue, reusable settings and voice tracks. Start with one campfire scene; see [SCENE_STUDIO_PLAN.md](SCENE_STUDIO_PLAN.md).

- Visual refinement from small-size and loop feedback.
- User-configurable timing and additional hand poses.
- More character adapters and optional video composition.
- Narration adapters and agent-specific installers.

Voice synthesis, an MCP server, paid model generation and Remotion integration are not implemented.
