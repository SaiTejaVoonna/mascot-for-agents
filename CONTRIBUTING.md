# Contributing

Contributions can add mascots, expressions, formats, accessibility fixes, or gallery improvements.

## Asset checklist

- Include editable source plus exported files.
- Preserve a consistent canvas, alignment, and transparent background where supported.
- Name files predictably: `<mascot>-<number>-<expression>.<format>`.
- Keep expressions readable at 32 px and 64 px; include a contact sheet for review.
- For loops, check the first/last frame seam and include a still PNG fallback.
- Include creator, source, and license information in the manifest. Do not upload art without permission.

## Agent workflow

Agents should inspect the existing manifest and source before editing, preserve the mascot's identity, make a small preview first, and validate exports visually. Rendering should be deterministic where possible and must not require a specific model provider or subscription. Never claim third-party assets are official or unrestricted unless the license confirms it.
